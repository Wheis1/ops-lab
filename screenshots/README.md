# 截图目录

## 命名规则

`序号-场景-日期.png`

示例：

- `01-nginx-reload-20261024.png`
- `03-disk-full-20261024.png`
- `05-redis-refused-20261025.png`
- `08-prometheus-alert-20261026.png`

## 每张截图要能证明什么

| 类型 | 截图内容 | 证明点 |
| --- | --- | --- |
| 部署 | `docker compose ps` 全绿 + 浏览器访问页面 | 真的跑起来了 |
| 监控 | Grafana 面板 + 钉钉告警截图 | 会配监控 |
| 排障 | 故障现场命令输出 + 修复后对比 | 会定位问题 |
| 脚本 | 脚本执行前后输出 | 会写自动化 |

## 注意

- 打码：公网 IP、密码、手机号、公司名
- 别放纯桌面截图，要能看清命令和输出
- 单张 < 1MB，多了会让仓库变大、加载变慢
